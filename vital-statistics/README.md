# Vital Statistics

Page: https://chartingwaterlooregion.ca/vital-statistics/

A standing page, not a post: fifteen line charts of key figures about Waterloo Region, each beside Ontario and Canada, covering the latest five years. Most sources update monthly or quarterly, a few once a year, so the page is refreshed rather than written once.

## Updating the page

Run from the project root, in this order:

1. `Rscript vital-statistics/R/01_get_data.R` fetches the latest figures from Statistics Canada and CMHC into `data-raw/` (a minute or two).
2. `Rscript vital-statistics/R/02_clean_data.R` rebuilds the tidy files in `data/`, `data/quality_flags.csv`, and `data/releases.csv` (each Statistics Canada table's release date, for the "Updated" date in the subtitles). Read what it prints: a new flag or footnote needs a row in the Reliability table below before the page will render.
3. `quarto render vital-statistics/index.qmd` redraws the charts. Rendering the page on its own always re-runs its code; a full-site `quarto render` would reuse the frozen results until `index.qmd` itself changes.

Then commit with `/save`. Each chart shows its own latest five years, so the charts end in different months: each source publishes on its own timetable.

## Reliability

| **Kitchener - Cambridge - Waterloo CMA:** every chart except the population charts shows the census metropolitan area for the Region, because it is the smallest area these tables publish. The CMA is six of the Region's seven districts; Wellesley Township, about 2% of the Region's people, is left out and nothing outside the Region is included. ## Reproduce

1. Run `R/01_get_data.R` (downloads the raw inputs into `data-raw/`).
2. Run `R/02_clean_data.R` (writes the tidy files into `data/`).
3. Render: `quarto render vital-statistics/index.qmd`.

## Notes

- No API keys are needed: Statistics Canada's web data service and CMHC's portal are open.
- Median absorbed price of new single-detached homes (CMHC's Market Absorption Survey) was planned but is not published through the `cmhc` package; the same-sample rent change chart took its place.
- Sampling: the Labour Force Survey and CMHC's Rental Market Survey are samples. The LFS publishes a standard error for each CMA estimate in table 14-10-0459; `02_clean_data.R` turns it into a 95% interval (estimate plus or minus 1.96 standard errors) for the unemployment and participation rates, and does the same with the standard error of the year-over-year change for the employment chart. Those charts draw the Region's interval as a band. The tables by age (14-10-0458, 14-10-0017) publish no standard errors, so those charts have none and say so. The EI chart divides an administrative count by the LFS labour force; no interval is worked out for the ratio. CMHC publishes a reliability rating rather than an interval for each Rental Market Survey figure.
- Crime: the incident rates use "Total, all violations", the same coverage as the Crime Severity Index (every Criminal Code violation, traffic included, and the federal statutes). The non-violent rate is all violations less violent Criminal Code violations, worked out in `02_clean_data.R`; both published rates share one population, so the difference is itself a rate per 100,000. Statistics Canada's headline "crime rate" instead uses Criminal Code violations excluding traffic.
