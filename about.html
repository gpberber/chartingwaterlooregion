About

What is it?

Charting Waterloo Region (CWR) is a local blog cobbled together to tell stories about life in Waterloo Region using data from (mostly) open sources. In snapshots—posts with a few charts and some basic analysis that can be read in under five minutes—and the occasional deep dive containing more rigorous analysis, CWR will answer questions from the fundamental to the frivolous. Has crime in the Region gotten worse over the past 25 years? CWR will take a stab at answering that. Which fast-food chain incurs more health-code violations, McDonald’s or Tim Hortons? CWR will bite into that one as well. (Thankfully, bad puns will not be a regular CWR feature.) Basically, CWR is one guy’s effort to illustrate facts and features of Waterloo Region using well-designed charts built from open data.

Who writes it?

The “one guy” in question is Greg Berberich. I was fortunate to achieve Freedom 55 at the end of 2023, retiring after 30 years as a Chartered Accountant, the last 25 spent in academia teaching and doing institutional research (I no longer hold the CA designation). As my undergrad degree in math, my PhD in accounting, and my decades as a CA indicate, I really like playing with numbers, so as boring as it may sound to most people, that’s what I spend a lot of my free time in retirement doing. CWR is my first blog and is basically me doing a hobby in public.

Why does it exist?

After years (no kidding!) of procrastination, I’ve decided to start publishing some of my charts and analysis because I have learned a lot of interesting and sometimes startling things from them, so I figure it’s worth sharing some of what I learn with other Region residents who want to know more about where they live. And to my knowledge, aside from Jeff Outhit, who does some excellent data journalism for The Record, there is no local outlet that regularly visualizes data about the Region. CWR exists to help fill this gap.

Where does its data come from?

CWR relies primarily on Statistics Canada tables and government open-data portals for its data, supplemented by data from other published sources. The README.md file in each post’s GitHub folder lists the post’s sources, with their links and licences.

Is it independent?

My area of expertise as an accountant was in auditing. An auditor’s most-critical asset is their independence because without it, their opinion is worthless. I therefore take my independence very seriously. CWR is not funded by or affiliated with any government, public service body, institution, or any other organization that could compromise my independence. All editorial decisions and opinions are mine alone.

How is it built?

I use R, a popular language for doing data science, to produce CWR’s charts and tables, and to prepare the data behind them. Quarto combines the R code with my writing and renders it into the HTML, CSS, and images needed to produce the CWR website. These website elements get pushed to a GitHub folder and then served to you via GitHub Pages.

GoatCounter counts page views and post likes so I know which posts people find interesting. The site sets no cookies and records nothing that identifies you, so there is nothing to opt out of.

Does it use AI?

Yes, I use Claude, an AI model made by Anthropic, primarily as the supplier of the code used to build the site’s infrastructure, to extract and transform the data, and to create the charts, although I do a lot of data-related coding myself (it’s fun!).

I make all editorial and design decisions, from the look and features of the site to the questions I answer, the analysis I do, and the charts I use, sometimes with Claude as a consultant.

I write the analysis and discussion in each post, including the chart titles and subtitles, with Claude serving as a copy editor to help me clean up and refine the post for publication. Every statistic in a post’s text and every data point in its charts is taken from the data by code, and all of that code is public (see next section), so you can check any of it for accuracy. Claude drafts the charts’ alt text for screen readers, each post’s README, and the data dictionary, then I review and edit them before posting. I take full responsibility for the final product.

Is it reproducible?

Yes, if you are so inclined, you can reproduce every post using the code and data in its associated GitHub folder. If you just want a post’s data, you can download a zip file containing the tables in CSV and Parquet formats, as well as an Excel workbook (when the tables are small enough), and a brief data dictionary describing the fields in each table. The “Reproducibility and data download” section at the end of each post contains links to the post’s GitHub folder and zipped data files.

Can its content be reused?

Yes, everything on CWR is reusable. The text and charts are published under CC BY 4.0, so they can be copied, shared, or republished, including in the news, as long as CWR receives credit. And all the code is MIT licensed, so it can be reused as well. All data stays under the terms set by whoever published it.

Could it contain mistakes?

Yes, I am human and can make mistakes. If you spot an error or have a question about the data, email me with the details. I will correct any post containing verified errors and add a dated note at the top of the post saying what changed.

How does it make money?

It doesn’t. CWR is a non-commercial venture, so it doesn’t have ads and it won’t ask you to pay for a subscription. If you find a post enlightening, hit the Like button or drop me an email. That’s all the reward I need.
